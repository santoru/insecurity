01 — Concept

The parentheses are the brand.

The name already contains the idea: security, with an (in) that reminds us nothing is fully secure. The wordmark sets the brackets in the signal colour, so the eye lands on the (in) first — a scope, a lens, the finding you are looking for in a sea of noise.

Scope

( )

Brackets frame the work: a target, a boundary, a test case. Used as the mark and as a quiet typographic device.

Signal

●

One bright mint accent, used sparingly: the active state, the key number, the focus ring. Never as a background for long text.

Ink

■

A near-black with a hint of green. Gives the brand its terminal-at-night calm without the hacker clichés.

Securing your S3 presigned URLs

Presigned URLs are convenient, fast and easy to get wrong. Here is what to check before you ship one.

A presigned URL is a link that carries its own credentials. Whoever holds it can read or write the object on behalf of the identity that signed it, until it expires. That makes the signing service the real security boundary, not the bucket policy.

Keep the expiry short

There is no built-in way to revoke a single URL. Set ExpiresIn to the shortest value your users can live with:

$ aws s3 presign s3://my-bucket/upload.png --expires-in 300
# → valid for 5 minutes, then useless
url = s3.generate_presigned_url("put_object", ExpiresIn=300)

Checklist

  • Sign with a dedicated, least-privilege role
  • Sanitise the object key — path traversal is a thing
  • Enable server access logging on exposed buckets
  1. Generate the URL server-side
  2. Return it to the client
  3. Upload directly to S3

12 — Implementation

Where things live

Change a token once and it updates everywhere. Jekyll compiles the Sass partials into two minified files.

Files
  • _sass/brand/_tokens.scss — colours, fonts, radii, shadows (CSS custom properties)
  • _sass/brand/_base.scss — elements, .display, .lead, .label

  • _sass/brand/_components-extra.scss — alerts, badges, dropdown, forms, cards (this page only)
  • _sass/_site.scss, _home.scss, _about.scss, _syntax.scss — site chrome & pages
